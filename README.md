# social-media-tracker

## `agentic-content-system/`

Mockup на агентска система за създаване на съдържание (14 агента) за личен бранд
в областта строителство / инвестиции в недвижими имоти, България.

Покрива: YouTube заглавия и thumbnails · концепции за long-form · hook шаблони ·
рамки за подаване на информацията (Sam Gaudet / Caleb Ralston) · 45–60 shorts на месец ·
растеж в YouTube, Instagram и Facebook · монетизация в 7 нива.

## Дефиниция на „готово" (Definition of Done)

Един long-form е готов само когато:
```
[ ] Заглавие избрано от 5 варианта (Агент 03)
[ ] 3 thumbnail концепции, 1 избрана (Агент 04)
[ ] Хук от 8 варианта, ниво SHARP (Агент 06)

[ ] Проверката за 90 секунди е минала през ВСЕКИ блок, не само през най-дългия (Агент 05)
[ ] Скрипт минал anti-AI филтъра (Агент 07)
[ ] Минимум 6 маркера [SHORT] в скрипта
[ ] Описание с ключови думи + дисклеймър
[ ] Един CTA, не повече (Агент 12)
[ ] Compliance подпис (Агент 10)
[ ] 3 shorts готови за деня преди / деня на / деня след
[ ] FB native версия качена
[ ] End screen към конкретно следващо видео
[ ] Закачен коментар написан предварително
```

## Кризисен протокол

| Ситуация | Действие |
|---|---|
| Партньорът е в чужбина 3 седмици | Пусни резервния буфер (8 shorts) + 1 архивен long-form. Никога не спирай ритъма. |
| Видео се проваля (< 30% AVD) | Не паникьосвай. Правило на 3-те видеа (Агент 11). Едно видео е шум. |
| Негативен коментар за фирма/лице | Изтрий, ако е клевета. Отговори публично, ако е критика по същество. Никога не влизай в спор. |
| Compliance RED | Активът спира. Юрист. Няма изключения. |
| Atlanta оттегли данни | Смени епизода с резервен от банката. Никога не публикувай неодобрени данни. |
| Вирален short без връзка с нишата | Не го експлоатирай. Той носи грешна аудитория, която разваля сигнала на алгоритъма. |

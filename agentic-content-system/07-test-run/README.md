## Какво тестът НЕ доказва

Няма заснет кадър. Числата са модел. Тестът показва, че **конвейерът произвежда
пълни, изпълними изходи и че диагностиката хваща грешки** — не че тези конкретни видеа
ще направят тези конкретни числа.

Четири неща се тестват само на терен: дали партньорът звучи естествено, дали 15 shorts
на седмица издържат до месец 6, дали Atlanta пуска числа навреме, и дали разговорите стават сделки.

# AGENTIC CONTENT SYSTEM
### Mockup на агентска система за органичен маркетинг
**Клиент:** личен бранд · строителство · инвестиции в имоти · България
**Собственик:** Creative Director

---

## Какво е това

Mock up на **14-агентен конвейер**, който произвежда всеки месец:

| Изход | Количество |
|---|---|
| YouTube long-form (пакетирани изцяло) | **4** |
| Shorts (YT / IG / FB) | **45–60** |
| IG карусели | **8** |
| FB нативни качвания + групи | **4 + ежедневно** |
| Growth ревю + Monetization ревю | **1 + 1** |

При **2 снимачни дни на месец** ангажимент от таланта.

Изградено върху публично изследвани рамки на **Sam Gaudet** (Creative Director, Martell Media)
и **Caleb Ralston** — адаптирани за български пазар, кирилица и регулиран финансов контекст.
Изследването и източниците: `02-frameworks/presentation-frameworks.md`.

## Двата гейта

**GATE 1 — Packaging.** Тема, която не мине, е спестила 12 часа продукция. Това е успех.
**GATE 2 — Compliance.** ⛔ Не е декорация. Фонд + доходност + публичен канал = регулирана територия
(ЗДКИСДПКИ / AIFMD, КФН). Виж `01-agents/10-compliance-agent.md`.

## Статус

Това е **mockup** — архитектура, рамки, шаблони и напълнена банка със съдържание.
Не е свързан с API-та и не публикува. За производство следващите стъпки са:
свързване на YouTube Data API + Meta Graph API към Агент 11, CRM за Агент 13,
и юридически преглед на Агент 10 от лицензиран консултант.
